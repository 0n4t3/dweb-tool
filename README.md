## DWeb-Tool
A simple tool for downloading files on decentralized protocols in the browser, no gateways or cors proxies required. For people such as myself who love the idea of decentralized protocols, only to go "My dang, I'm on my tablet and I don't have IPFS installed, and using a gateway is just centralized servers with extra steps."

Supports:

* IPFS via Helia
* Torrents via Webtorrent
* Blossom via Claude's makeshift library
